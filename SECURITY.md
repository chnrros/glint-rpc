# Security

If you find a security vulnerability in Glint, please report it privately
rather than opening a public issue.

Use GitHub's **[Report a vulnerability](../../security/advisories/new)**
button (Security tab → Advisories → "Report a vulnerability") on this
repository. That opens a private draft advisory that only you and the
maintainers can see, so the issue can be reviewed and fixed before it's
public.

Please include:

- What the vulnerability is and its potential impact.
- Steps to reproduce it.
- The platform and version of Glint you tested it on.

We'll acknowledge reports as soon as we can and follow up once a fix is
available. Thanks for helping keep Glint and its users safe.
